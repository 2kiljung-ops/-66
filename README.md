# Steel Sales AI — 철강 영업 자동화 에이전트 MVP

## 실행 방법
1. `index.html` 파일을 Chrome 또는 Edge에서 엽니다.
2. 상단의 `엑셀 가져오기` 또는 `데이터 가져오기` 메뉴에서 거래처 엑셀(.xlsx/.xls)이나 CSV를 선택합니다.
3. 거래처 관리에서 검색하고, 영업 파이프라인에 고객별 기회를 등록합니다.
4. 견적·마진 계산에서 판매 단가와 비용을 입력해 계산하고 저장합니다.
5. `전체 데이터 백업`으로 JSON 백업을 주기적으로 저장합니다.

## 현재 포함 기능
- 통합 대시보드: 거래처 수, 진행 중 영업기회, 파이프라인 금액, 수주 금액
- 거래처 관리: 엑셀/CSV 가져오기, 이름 기준 중복 간단 필터, 검색, 수동 등록, CSV 내보내기
- 영업 파이프라인: 단계/금액/예상 수주일/다음 행동 관리
- 견적·마진 계산: 매출, 추정 원가, GP, GP율, 목표 GP율 비교
- 시황 브리핑 입력 양식: 기준일·주제·출처·확인된 내용·영업 행동 저장
- 브라우저 로컬 저장, JSON 백업 및 CSV 내보내기

## 중요한 제한
- 이 버전은 브라우저에서 실행하는 단일 사용자 MVP입니다. 서버·로그인·권한·다중 사용자 동기화·자동 이메일/CRM 연동은 없습니다.
- 엑셀 판독은 SheetJS CDN을 사용하므로 첫 실행 시 인터넷 연결이 필요합니다.
- 고객 데이터는 현재 브라우저의 localStorage에 저장됩니다. 공용 PC에서 사용하지 말고 정기적으로 백업하세요.
- 거래처 중복 판정은 이름 기준의 단순 비교입니다. 사업자등록번호 기반 중복 제거, 폐업 여부, 상호 변경은 자동 확정하지 않습니다.
- 실시간 철강 가격/뉴스 연결은 아직 없습니다. 브리핑 화면은 검증된 출처를 입력하는 양식입니다.
- 견적 계산은 추정치이며 금융비용·재고손실·환율·결제조건 등을 회사 정책에 맞게 추가해야 합니다. AI가 가격을 자동 확정하거나 외부 발송하지 않습니다.

## 다음 개발 단계
1. 실제 거래처·판매 실적 파일의 열 이름과 시트 구조를 분석해 정확한 가져오기 매핑 구성
2. 사업자번호/거래처코드 기반 중복 및 거래처 통합 규칙 설계
3. 판매 실적과 월별 목표 자동 연결, 품목·업종별 매출/GP 대시보드
4. 사용자 로그인·데이터베이스·권한·백업을 갖춘 서버형 웹앱
5. 승인형 AI 기능: 고객 우선순위, 후속 영업 문안, 시황 요약 및 견적 검토
6. 신뢰 가능한 시황 소스와 갱신 시각을 표시하는 데이터 커넥터

## 기본 목표 참고값
기존 `2027_부일에스티_철강사업_판매목표_관리표.xlsx` 기준: 연 매출 30억원, 목표 GP율 8%, 신규 우량 고객 20개, 프로젝트 12건. 실제 운영 목표로 사용하기 전에 최신 경영계획과 일치하는지 확인하세요.
